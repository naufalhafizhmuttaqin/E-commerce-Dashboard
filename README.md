# 📊 E-Commerce Sales Analysis Dashboard

An end-to-end Data Analytics project that demonstrates the complete analytics workflow, from raw data cleaning to interactive business dashboard development.

This project focuses on analyzing e-commerce sales data to uncover sales trends, customer behavior, product performance, and operational insights using Python, SQL, and Power BI.

---

## 📌 Project Overview

The objective of this project is to transform a raw and messy e-commerce dataset into meaningful business insights through a structured analytics process.

The project covers:

- Data Cleaning using Python (Pandas)
- Exploratory Data Analysis (EDA)
- SQL Business Analysis
- Interactive Dashboard Development in Power BI

## 🧹 Data Cleaning

The raw dataset contained several data quality issues, including:

- Missing values
- Duplicate records
- Inconsistent text formatting
- Mixed date formats
- Incorrect total price calculations
- Invalid quantity values
- Outliers
- Inconsistent payment methods
- Inconsistent city names

All cleaning processes were performed using Python and exported as a clean CSV dataset for further analysis.
